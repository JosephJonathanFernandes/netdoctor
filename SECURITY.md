# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 2.0.x   | :white_check_mark: |

## Reporting a Vulnerability

NetDoctor is a local desktop application with no cloud backend or user accounts. It does not collect or transmit personal data beyond direct network measurements to public endpoints (speedtest.net, 1.1.1.1, etc.).

If you discover a security issue, please open a GitHub issue or contact the repository owner directly. Do not submit sensitive information through public issues.
